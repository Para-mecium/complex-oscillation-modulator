# FHN Network Complexity Analysis

Main entry:

```matlab
run_fhn_complexity_analysis
```

The script is intentionally written as a numerical example. Edit the first
`User settings` block directly:

```matlab
N_list = [10, 20, 40, 80];
M_list = [3, 5, 7, 10];
target_count_list = [1, 2, 4, 8];
err_bound_list = [1e-6, 1e-8];
dlambda_cap_list = [0.02, 0.05, 0.1];
network_type_list = {'ER', 'BA', 'SW', 'FC'};
coupling_type_list = {'synapse', 'gap'};

target_property = 'varAmp';
target_node_indices = [];
target_values = [];

controlled_parameter_name = 'I';
controlled_node_indices = [];
```

`target_values = []` means the target is generated by shifting the current
value by `target_relative_shift`. Fill `target_values` to prescribe the
targets explicitly.

The FHN parameters are stored as vectors:

```text
theta, gamma, epsilon, tau, I, V
```

Scalars in `base_params` are expanded to all neurons. Set
`parameter_noise_strength = 0` for identical neurons, or a positive value for
small reproducible heterogeneity.

Coupling definitions:

```matlab
synapse: omega * sigma, sigma = 1 ./ (1 + exp(-tau .* (v - V)))
gap:     omega * v - sum(omega, 2) .* v
```

`FC` is a fully connected directed network with zero diagonal. Its raw
off-diagonal weights are sampled uniformly from `[0.2, 1]`, then scaled by
the network scale used in `run_fhn_complexity_analysis.m`.

Saved data uses one file per sweep value:

```text
data/<baseline_setting>/<sweep_field>_sweep/<sweep_field>=<value>.mat
```

Examples:

```text
sys_dim_sweep/sys_dim=5.mat
truncation_order_sweep/truncation_order=20.mat
target_num_sweep/target_num=10.mat
```
